# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Assume good faith, and stay focused on the work. Harassment,
discrimination and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub, by opening a private
security advisory marked "conduct". Reports are handled confidentially. Maintainers may remove
content or contributors that violate the code.
