# @iso20022-bank-kit/cli

`ibk`: developer tools for ISO 20022 bank integrations. Validate messages, convert MT940/942 to camt.053, check and build IBANs, check BICs, build pain.001, export JSON Schemas, serve GraphQL and MCP, and run conformance. Run `ibk help` for the full list.

```sh
npx ibk validate pain001.json --connector bac
```
