# @iso20022-bank-kit/connector-bac

**Unofficial** connector for BAC Credomatic API Center 2.0: Panamá, Costa Rica, Nicaragua, Honduras, El Salvador and Guatemala. Covers balances (camt.052), statements (camt.053, MT940, MT942), payments (pain.001) and tracking (pain.002).

> Not affiliated with, sponsored by, or endorsed by BAC Credomatic. "BAC" and "BAC Credomatic" are trademarks of their owner and are used only to identify the API this connector targets. No BAC documentation is included.

```ts
import { bacConnector } from '@iso20022-bank-kit/connector-bac';
```
