# @iso20022-bank-kit/graphql

GraphQL server generated from the installed connectors. Each connector is a top-level field with its own typed connection input. Introspection is on and enums are strict, with `UNKNOWN` plus the raw code on output.

```ts
import { createGraphQLHandler } from '@iso20022-bank-kit/graphql';
```
