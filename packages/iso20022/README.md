# @iso20022-bank-kit/iso20022

Domain model, ISO 20022 code maps, validators (IBAN mod-97, BIC, decimal amounts), builders and parsers for pain.001, pain.002, camt.052, camt.053, camt.060, tsmt.038, admi.002 and admi.004, and JSON Schema export.

```ts
import { buildCustomerCreditTransferInitiation, parseStatement, isValidIban } from '@iso20022-bank-kit/iso20022';
```
